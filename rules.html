PARTICIPATION

Participation rules

Core rules for systems, data, and evaluation.

01

Declare one system per track

For each track they enter, teams must declare one system: one text system for all tasks T1–T4 and one vision-language system for V1. The same system may be used for both tracks, but a separate submission is required for each track.

02

Prepare your training data

Teams are responsible for preparing their own training data. Organizers will not provide a training dataset. Synthetic data, self-created data, and data collected from the web may be used.

03

Choose a model-size band

Text / LLM models use four bands: Tiny (P ≤ 1B), Small (1B < P ≤ 8B), Medium (8B < P ≤ 30B), and Large (P > 30B). Vision / VLM models use three bands: Small (P ≤ 8B), Medium (8B < P ≤ 30B), and Large (P > 30B). P is the total number of model parameters; B means billion. For mixture-of-experts (MoE) models, all expert parameters count, including experts that are not active for a given input. For vision-language models, the vision encoder parameters are included in P. Boundary values belong to the lower band, and neither track has gaps between bands. Each model-size band has a separate ranking within each track.

04

Use a compatible model

Any model architecture is allowed if it meets the parameter limits of its band and is compatible with the Hugging Face Transformers library.

05

Submit a Transformers-compatible model

The model must load and generate outputs locally with the Hugging Face Transformers library. Include model weights, required tokenizer and configuration files, any required processor files, and run instructions.

06

Run inference locally

During evaluation, all outputs must be generated by the submitted model running locally through the Hugging Face Transformers library. External APIs, remotely hosted models, and online services may not be used to generate outputs.

07

Use validation data; final testing is private

A validation dataset will be shared for model development and hyperparameter selection. Final evaluation uses a private test set that will not be shared with participants; official rankings are based on those results.

08

Submit through the announced platform

Upload the model through the platform announced by the organizers. Platform details, technical submission requirements, and the submission schedule will be announced separately.
