LEADERBOARDS

Separate rankings for each track

Each track is evaluated separately.

P is the total number of model parameters, including all MoE expert parameters and, for vision-language models, vision encoder parameters. In Text / LLM, exactly 1B belongs to Tiny, exactly 8B to Small, and exactly 30B to Medium. In Vision / VLM, exactly 8B belongs to Small and exactly 30B to Medium.

01

TEXT / LLM

Text leaderboard

Use one system for all text tasks (T1–T4). The Culture Score combines T1 and T2; T3 and T4 are reported separately.

CategoryParameter range
TinyP ≤ 1B
Small1B < P ≤ 8B
Medium8B < P ≤ 30B
LargeP > 30B

VISION / VLM

Vision leaderboard

Use one system for the vision task (V1). Each system is ranked within its model-size band. The same system may serve both tracks, but each track requires a separate submission and is evaluated separately.

CategoryParameter range
SmallP ≤ 8B
